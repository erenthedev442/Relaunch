# Play on Legendary — Install Guide

Welcome! This is a one-time setup, about **15 minutes**. After this, you just
double-click to play.

You need a **Windows PC**, the **FFXI game files**, and our **launcher** (below).
You do **not** need an active Square Enix subscription to play on Legendary —
but you do need the game installed.

---

## Step 1 — Install Final Fantasy XI

Install the retail client (we connect to it; we never change your game files):

- **Official free download (recommended):** Square Enix's **PlayOnline** installer — **[download the FFXI client here](https://www.playonline.com/ff11us/download/media/install_win.html)**. It's the full game; you don't need a paid subscription to play on Legendary.
- **Or** the **Steam** version — search **"FINAL FANTASY XI"** on Steam and install it.

Then **launch FFXI once through PlayOnline and let it fully update.** This is
important — the game must be up to date before it can connect to Legendary.
(You can close it once it finishes updating; you won't use PlayOnline again.)

> 💡 Tip: install FFXI somewhere simple like `C:\FFXI`, not inside
> `C:\Program Files` (Windows permissions there cause headaches).

---

## Step 2 — Download the Legendary launcher

1. Grab **`Legendary-Launcher.zip`** from our Discord: **<#downloads — paste link>**
2. **Unzip it** somewhere easy (your Desktop is fine). Don't run it from inside
   the zip — actually extract the folder first.

This is **Ashita v4**, pre-configured to point at our server. You don't have to
type any addresses or ports — it's already set.

---

## Step 3 — Launch the game

Open the unzipped folder and double-click **`Play Legendary.bat`**
(or run `Ashita.exe` and click **Play**).

The first time, Ashita finds your FFXI install automatically. If it asks where
FFXI is, point it at the folder from Step 1.

---

## Step 4 — Make your account (automatic)

The first time you connect, you'll be asked for a **username** and **password**.
**Pick new ones** — your account is created instantly on the spot. There's no
website signup and no email.

> ✍️ **Write your username/password down.** There's no "forgot password" email —
> if you lose it, ask an admin in Discord.

---

## Step 5 — Create a character and play!

Make your character and you're in. New here? Head to **GM Home**, talk to the
**Unlocker** to get set up, and check the **#new-players** channel in Discord for
where to start. Welcome to Legendary! 🎉

---

## Troubleshooting

**"Ashita can't find FFXI" / no install detected**
→ Install and fully update FFXI first (Step 1). Then in Ashita, point it at your
FFXI folder once.

**Stuck on "connecting" / it won't log in**
→ Make sure FFXI finished updating through PlayOnline (Step 1). Try again — the
first connect can be slow. If your antivirus/firewall prompts, allow Ashita.

**A "POL-####" error when launching**
→ Usually a client/Windows fix: run as Administrator, and install the Microsoft
**Visual C++ Redistributables** if you don't have them. Still stuck? Post the
exact error in **#help**.

**Anything else**
→ Drop a message in **#help** on Discord — we'll get you in: **<Discord invite — paste link>**
