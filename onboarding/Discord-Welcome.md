# 🏆 Welcome to Legendary

A custom **Final Fantasy XI** server built to be played **your way** — high-level
custom content, fully **solo-friendly** (trust support, no group required),
quality-of-life unlocks, a living player economy, and progression you won't find
on retail.

We're small and growing — get in early and help shape it. 💪

## ▶️ How to join — ~15 min, one time
**1.** Install **Final Fantasy XI** (Steam or PlayOnline) and let it fully update.
**2.** Download the launcher in **#downloads** and unzip it.
**3.** Double-click **`Play Legendary`** → pick a username & password → you're in!
