# Gear vs Retail

This page shows how the server's item stats compare to **retail FFXI** (source: FFXIAH.com).

Three categories are tracked:

- **Missing / lower on server** — retail has the stat but the server doesn't, or the value is smaller. Can indicate bugs or pending work.
- **Different values** — stat exists on both but with a different number.
- **Server-only buffs** — the Relaunch server adds a stat the retail item doesn't have. These are intentional upgrades.

> Retail source is [FFXIAH.com](https://www.ffxiah.com). The comparison is updated when the FFXIAH cache is refreshed (usually monthly). Some "missing" entries reflect LSB implementation choices (e.g. implementing "Damage taken" as separate physical/ranged mods rather than a single all-types mod — functionally similar but recorded differently).
