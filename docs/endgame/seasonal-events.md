# Seasonal Events

From time to time — around holidays and special occasions — the server runs a **seasonal event** that boosts the marks you earn from Hunting League kills. During an event window, every qualifying kill pays a **mark multiplier** on top of your usual amount, for a limited time.

!!! tip "Summary"
    During a seasonal event, Hunting League kills earn bonus marks (a mark multiplier) for a limited time. Check below to see whether one is running.

## How it works

When an event is live, the bonus is fully automatic — just keep hunting. Each event has:

- A **name** that appears in the kill bonus message so you know it's active.
- A **mark multiplier** (for example, 2× for double marks or 1.5× for a 50% bonus) applied on top of any Hunter's Guild amplifier you've already earned.
- A **start and end time** in UTC. The bonus only applies to kills made inside that window.

Only one event bonus applies at a time, so you always get the best multiplier that's currently running.
