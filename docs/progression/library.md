# Celennia Memorial Library — Beginner Hub

The Celennia Memorial Library is the relaunch's **starting hub** — convenience services, gil sinks, and getting-started tools all live here.

## Getting around & set-up

| NPC | What it does |
|---|---|
| **Homepoint** | Set your home point and teleport between unlocked ones. |
| **Warpman** | Paid gil warps to the cities, expansion areas, remote zones, and endgame spots. |
| **Race Changer** | Change your character's race for gil. |

## Currencies & exchanges

| NPC | What it does |
|---|---|
| **Gil Exchange** | Trade hunt marks for gil in bulk. |
| **Sparks Exchange** | Spend Sparks of Eminence on gear and items. |
| **Crafting Exchange** | Trade for crafting materials. |
| **Title Broker** | Buy cosmetic titles for gil. |
| **Cosmetic Shop** | Pure-cosmetic outfits and hats, bought with Allied Notes. |

## Activities & boards

| NPC | What it does |
|---|---|
| **Daily Board** | Pick up and turn in daily objectives. |
| **Hunt Board** | Weekly NM-target bounties — turn them in for hunt marks. |
| **Unity** | Unity Concord "Wanted" NM fights. |
| **Casino** | Gil-sink gambling games (Lady Luck). |
| **Mystery Mog** | Gacha box — spend hunt marks for a random reward pull. |
| **Chocobo Derby** | Chocobo racing and betting. |

---

*New-character set-up (weapon skills, spells, key items, missions, maps, etc.) is now granted **automatically at character creation** — there's no longer an Unlocker NPC to visit.*
