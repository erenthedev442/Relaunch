# Celennia Memorial Library → moved to The Hub

The former Celennia Memorial Library beginner hub has been consolidated onto a single island plaza on **Purgonorgo Isle**. All of its NPCs — home point, Warpman, the Gil / Sparks / Crafting exchanges, Title Broker, Cosmetic Shop, Daily & Hunt boards, Unity, Casino, Mystery Mog, Chocobo Derby, and the Race Changer — now live there.

➡️ **[The Hub — Purgonorgo Isle](hub.md)** — reach it with **`!hub`** (`!lib` still works and lands you there).
