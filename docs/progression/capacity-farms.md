# Capacity Point Farms

Two always-open camps built for one thing: turning time into **Job Points**.

## How it works

<!-- DOCGEN:BEGIN id="cp-overview" -->
Grinding **Capacity Points** for Job Points? Relaunch keeps two dedicated **CP farm camps** running around the clock. Each is a pool of **always-up Lv150-160 mobs** with low HP that **respawn instantly**, use **shared claim** (anyone can help, everyone gets credit), and drop **no loot** — pure, uninterrupted Capacity Point farming. Warp in with the command, pull, repeat. (CP is boosted server-wide, so a session here fills Job Points fast.)
