## Notes

- **Snapshot, not live.** These tables update only when `refresh-site.bat` runs. If you just earned that #1 spot, it'll show up after the next refresh.
- **Names are real.** The character names below are the actual in-game names of players on this server. Opt out with the command above if that's not for you.
- **Inactive characters still appear.** Logging out doesn't remove you. The tables show who's done the most ever, not who's online right now.
- **Two flavors of Reforge boards.** *Current Balance* boards reflect what each character holds right now — spending marks drops you on those. The *Lifetime Marks Earned* board is monotonic — it only goes up, measuring true grind regardless of spending.
- **NM Slayers counts both systems.** Each successful Hunting League or Reforge Spawner NM kill bumps the same counter; you don't need to specialize to climb.
